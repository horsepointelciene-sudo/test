# 4H-SiC UMOSFET / IV / BV / 栅氧电场 / 扩展仿真参考

## 基本结构与参数

典型结构由 N+ 源区、P-body、P+ 体接触、沟槽栅及栅氧、N− 漂移区、N+ 衬底和背面漏极组成。P-body 通常通过 P+ 接触与源极短接；P 型屏蔽、CSL 和超结不是所有 UMOSFET 的必备结构。

| 参数或区域 | 直观作用 | 建模时记录 |
|---|---|---|
| 元胞节距、完整/半元胞 | 决定单位面积的沟道数量 | 模拟横向范围、对称面、出平面宽度、并联元胞数 |
| 沟槽宽度、深度、侧壁角、底角半径 | 决定沟道与局部电场 | 在最终结构量测，不能只累加工艺命令数值 |
| 侧壁和底部氧化层厚度 | 决定栅控、耦合与介质电场 | 两者分开记录，不能用一个 tox 代替所有位置 |
| P-body 深度和横向轮廓 | 决定有效沟道及穿通风险 | 净掺杂结位置、侧壁有效沟道长度、体接触路径 |
| N+ 源区、P+ 接触区 | 电子注入与体区电位钳位 | 接触实际覆盖区域、掺杂补偿、是否连通 |
| 漂移区厚度与掺杂 | 耐压和导通电阻的主要权衡 | 最终厚度、分布、温度、电离模型 |
| CSL、JFET 狭窄区 | 影响电流扩展和局部电阻 | 是否存在、宽度、浓度、耗尽状态 |
| P 型屏蔽或深 P 区 | 重新分配电场并保护栅氧 | 接源或浮空、位置、宽度、与导电通路的间距 |
| 栅材料、功函数、接触电阻 | 决定栅控和端口压降 | 参数来源、接触类型、是否显式模拟多晶硅耗尽 |

几何常用 µm，氧化层也常用 nm；掺杂常用 cm⁻³，注入剂量常用 cm⁻²，能量常用 keV。必须按具体命令核对单位，不能把 SProcess 中带单位的输入与其他模块的默认单位混用。

## 工艺、掺杂与几何检查

1. 确认建模路线是 SProcess 工艺仿真还是 SDE 理想结构；前者检查刻蚀、氧化和激活后的轮廓，后者说明理想化假设。
2. 区分注入剂量、化学浓度、替位激活浓度和电离浓度。工艺参数标签不是最终均匀浓度。
3. 检查 N+ 源区是否与侧壁沟道衔接、P-body 是否接源、沟槽是否穿过所需体区、栅氧是否连续、gate/source/drain 是否接在正确边界。
4. 工艺重网格后重新检查接触、薄氧化层、掺杂峰与结位置；细网格不能修复错误几何。
5. 有 P 型屏蔽时确认其电连接。浮空屏蔽与接源屏蔽的静态电位及瞬态响应不同。

对超结变体，在相同深度和统计域内检查 P/N 柱宽及有效电荷。均匀理想柱的一阶比较可用 `N_D × W_n` 与 `N_A × W_p`；实际非均匀、补偿和不完全电离结构应计算空间积分并说明偏压与温度。局部 Al 注入不自动证明已经形成满足设计目标的超结。

## 晶向、不完全电离与材料参数

### 晶向和各向异性

4H-SiC 沿不同方向的输运和电离响应可能不同。沟槽侧壁表面方向也影响沟道，因此体迁移率各向异性与界面迁移率的晶面依赖应分别处理。

- 记录晶圆法向、偏切、沟槽走向和模拟坐标，核对参数文件中的 `LatticeParameters` 以及模型的方向设置。
- 不预设 x 一定水平或一定竖直；SProcess、结构变换与 SDevice 读入坐标需要对应。
- 按实际模型逐项核对迁移率、雪崩、介电常数及热导率的方向处理，不认为启用一项就启用了全部。
- 各向异性离散方法有网格适用条件，不把 `TensorGridAniso` 当成所有沟槽网格的固定答案。

W-2024.09 手册第 28 章讨论各向异性，第 924 页说明晶体与模拟坐标。具体方向向量必须来自本器件坐标，不能复制别人的 `(1,0,0)`。

### 不完全电离

“杂质已经激活”不等于“杂质全部电离”。SiC 中氮施主、铝受主的电离程度会影响体区电位、阈值、导通与阻断，应作为材料模型的一部分核对。

以下只展示模型入口，依据 W-2024.09 SDevice 手册第 365 页；**尚未运行验证，不是完整 Physics 配置**：

```tcl
Physics {
  IncompleteIonization
}
```

具体使用前检查材料、TDR 杂质字段、各物种电离参数，以及多晶格位点分配。若用 `Split`，分配权重应归一且与物种参数匹配；本工程里出现的某组权重不应成为所有项目的固定默认值。

可检查 `DonorPlusConcentration`、`AccepMinusConcentration` 与 active 掺杂的差别，名称依据手册第 366 页。不要只凭 `Doping` 字段名称推定它是化学净掺杂，必须核对该输出量的定义。

## SiC/SiO₂ 界面与沟道迁移率

UMOSFET 的导通既取决于能否形成沟道，也取决于沟道里的电子能否有效移动。阈值和导通电流同时偏差时，应分别检查栅控与散射机制。

| 内容 | 主要影响 | 需要区分 |
|---|---|---|
| 固定界面电荷 | 改变界面静电和阈值 | 符号、位置和面密度；不是可随占据变化的 Dit |
| 界面陷阱 | 改变占据、电荷、复合和动态响应 | donor/acceptor、能量参考、分布、俘获截面、初态 |
| 界面迁移率 | 影响侧壁沟道电阻与栅压依赖 | 法向场、表面散射、晶面和温度校准 |
| 体迁移率 | 影响漂移区和体内电流 | 掺杂、高场、温度和方向依赖 |

W-2024.09 手册第 572–574 页支持以下区别：界面 `Level` 的 `Conc` 单位为 cm⁻²，其他能量分布通常为 cm⁻²·eV⁻¹；体陷阱相应为 cm⁻³ 或 cm⁻³·eV⁻¹。`FixedCharge` 的 `Conc` 符号表示电荷符号。用库仑面电荷表达的 Qf 还需通过元电荷换算，不能直接当成相同数值的 `Conc`。

下面仅示意零固定电荷的界面声明；材料名称需与实际结构匹配，**尚未运行验证**：

```tcl
Physics(MaterialInterface="SiliconCarbide/Oxide") {
  Traps((FixedCharge Conc=0))
}
```

全材料界面设置可能同时作用于侧壁、底部和表面氧化层；若设计需要区分位置，应核对实际区域名和 `RegionInterface` 作用范围。不要一面用显式陷阱改变界面响应，一面再无依据地降低迁移率重复拟合同一效应。

建议先用匹配晶面和工艺的 MOSCAP C–V/频率/温度数据约束界面静电，再以 MOSFET 低漏压 Id–Vg 与温度特性约束沟道迁移率。MOSCAP 也需明确频率、扫描历史及陷阱响应，单条曲线通常不能唯一确定所有参数。

## 网格、精度与收敛

优先细化沟槽侧壁沟道、薄栅氧、底角、PN 结、屏蔽区边缘和狭窄电流通路。漂移区、衬底按耗尽层及场梯度分级设置，避免为了侧壁精度全局细化。

- 在氧化层厚度方向和沟道法向解析电势与载流子梯度，检查单元质量及界面两侧网格。
- 尖锐理想角可能使峰值场随网格继续增大。优先使用有物理依据的底角半径，并报告峰值位置和网格依赖。
- 在其余设置不变时比较网格细化前后的 Vth、Ron,sp、BV、氧化层峰值场；容许变化事先按任务精度定义。
- 宽禁带低载流子区可评估扩展精度、误差参考量、线性求解器和阻尼；`Digits`、迭代数与步长没有跨工程通用最优值。
- 从平衡态逐步建立目标偏压；初始化顺序、所求载流子方程和延续方式按任务设计。涉及雪崩、体二极管或辐射时不能用忽略空穴的基线替代最终模型。
- 改小扫描步长属于数值调整；降低陷阱浓度、关掉雪崩或改变迁移率属于物理改变，必须单列。

遇到失败时结合完整日志定位发生在哪一步、哪个偏压、哪条方程和哪个空间位置，并查看该点之前的场数据。不要通过无限放宽收敛标准证明结果可信。

## Id–Vg、Id–Vd 与参数提取

### 建立基线

1. 平衡态：检查接触、净电荷、能带和 PN 结位置。
2. 低漏压 Id–Vg：固定 Vds、温度及源体条件，检查栅控、亚阈值和 Vth。
3. Id–Vd：在指定多个 Vgs 下扫描，分别检查低压电阻、高场和自热影响。
4. 在授权范围内扩展温度、网格或模型敏感性；所有对比使用相同归一化定义。

Vth 必须注明恒流法或其他提取方法、参考电流及其单位、Vds 和温度；不同方法的数值不能直接混比。Ion、Ioff 同样需要明确偏压和归一化。

### 电流和面积

二维截面不是完整芯片。先写明模拟代表的出平面宽度、完整/半元胞、元胞数和对称关系，再解释端口电流。W-2024.09 手册第 59 页说明：全局 `AreaFactor` 缩放接触电流和电荷，且与对应接触的 `AreaFactor` 相乘。它不能脱离几何直接等同于芯片面积。

```text
R_on    = V_DS / I_D                   # 指定低压工作点的静态比值
r_on    = dV_DS / dI_D                 # 指定点附近的微分电阻
R_on,sp = R_on × A_active              # Ω·cm²；面积与电流代表同一范围
```

若使用微分定义，需明确报告 `r_on × A_active`，不能与静态比值混淆。也可用 `V_DS / J_D`，前提是 J_D 已按同一有源面积归一化。换成 mΩ·cm² 时乘 1000；µm² 转 cm² 时乘 10⁻⁸。不要混用 A、A/mm、A/µm 和 A/cm²，或把已缩放电流再次乘元胞数。

Ron,sp 的面积通常按顶视有源元胞占地定义；若用包含终端的芯片总面积，应明确注明。不同面积口径会直接改变比较结论。

## BV 与栅氧电场

### 关断击穿

1. 固定并记录 Vgs、源体连接、温度与漏端边界，从平衡态建立关断偏压。
2. 明确提取的是固定电流判据、离化积分估计，还是外电阻/延续法得到的 I–V 拐点；这些定义不自动等价。
3. 保存接近泄漏上升前后多个偏压点的场数据，检查电场、雪崩生成、电子/空穴电流及耗尽区。
4. 有外电阻或混合模式时，用器件实际漏源端电压提取 BV，不把外部电源电压当成器件电压。
5. 区分雪崩、穿通、寄生双极导通、边界影响和数值失败。步长过小或迭代失败本身不是 BV 判据。

电流停止阈值必须与归一化对应；`BreakCriteria` 结束扫描不等于自动证明该点发生了预期击穿。只有元胞而没有终端的模型不能证明完整芯片终端耐压。

### 栅氧电场

同一漏压下分别报告 SiC 与氧化层内的电场峰值、位置和对应 Vgs。界面两侧法向场可以不同，因此 SiC 侧峰值不能替代氧化层峰值。

- 关注底角、侧壁和氧化层厚度过渡处，必要时沿界面及氧化层内部提取截线。
- P 型屏蔽、厚底氧、沟槽圆角和节距可能改变场与导通路径，需要同时比较 BV、Ron,sp、栅氧场和电容。
- 比较结构时固定偏压与面积口径，并检查峰值对网格、圆角和材料参数的敏感性。
- 不预设统一“安全栅氧场”。介质工艺、缺陷、应力时间和可靠性判据不同，瞬时电场只能作为风险指标之一。

相关原始研究讨论了屏蔽与 JFET 电阻之间的权衡：[Lan 等，2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11205807/)。该论文的结构和参数不是本文件的默认设计。

## 热、开关、光照及辐射扩展

仅在用户任务涉及相应目标时启用；扩展应从已核对的电学基线出发，不自动增加运行节点。

### 自热、短路和 UIS

热模拟需要同时核对热方程、热导率/热容及温度依赖、散热边界、接触热阻、初始温度和外部负载。缩短衬底或使用等温底边界可能改变散热结果，不能只为节省网格而忽略其影响。

短路和 UIS 应注明母线电压、栅驱动、负载或电感、寄生参数、脉冲时间和限流条件。电流变化、最高温度、热点位置和能量需联合分析；数值发散、超过某个任意温度或仅有高电流，不能单独证明永久损伤。

### 电容、栅电荷和开关

记录 C–V 的频率、偏压和端口条件。Qg 及米勒平台依赖漏端电压、电流和驱动电路，不能与任意静态电容直接等同。不同结构的开关损耗需在相同外电路、负载及面积条件下比较。

### 光照与超结光电变体

先确认当前节点是否真正启用光学生成，记录波长、入射功率密度、照射位置/方向、光学材料数据、时间包络及遮挡。光生载流子可能改变体区电位和导电通路，需对比暗态与光态的空间结果，不能只看总漏电流。带光学模块的历史工程不意味着所有 UMOSFET 都需要光学模型。

### HeavyIon / SEB / SEGR

1. 核对暗态 IV、关断漏电和 BV，再建立指定 Vgs/Vds 及温度的稳定初态。
2. 明确粒子轨迹、位置、方向、长度、径向分布、入射时刻及脉宽；空间网格和时间步长需能解析注入。
3. 核对 LET 的物理单位、SiC 密度及成对产生能。**MeV·cm²/mg 不能直接填入 `LET_f`。**
4. W-2024.09 手册第 813–815 页说明：`LET_f` 默认单位为 pairs/cm³；使用 `PicoCoulomb` 后为 pC/µm，且 `Length`、`Wt_hi` 的单位由默认 cm 变成 µm。二维/三维归一化不同，须核对同章表格和实际积分电荷。
5. 入射安排在偏压与热/陷阱初态稳定后；不沿用其他材料例子中的固定时刻或固定 BV 百分比。
6. 联合保存 I_D(t)、电流分量、温度（若求解）、雪崩及生成项、电流通路、体区电位和栅氧场。按用户授权的范围比较位置、LET 或电压。

| 现象 | 可以支持的判断 | 仍需核对 |
|---|---|---|
| 尖峰后回到稳定基线 | 在观察窗口内恢复 | 窗口是否足够、是否存在延迟响应 |
| 注入结束后仍有较大持续电流 | 持续导通或正反馈的线索 | 外电路、寄生双极、雪崩与电热证据 |
| 温度持续上升且热点局域化 | 电热失控的线索 | 热模型、能量输入、网格和时间步长 |
| 栅电流或栅氧场异常 | 介质受损风险线索 | 是否包含经校准的介质损伤/漏电机制 |
| 最小步长失败 | 数值求解失败 | 不足以单独判定 SEB 或 SEGR |

SEB 与 SEGR 分开记录：前者关注烧毁相关电热反馈，后者关注栅介质破坏。没有不可逆损伤模型或实验对照时，结论应限定为模拟到的恢复、持续导通、失控迹象或风险，避免宣称已预测永久烧毁。

## 常见异常定位

| 表现 | 优先排查 | 所需证据 |
|---|---|---|
| Vth 异常、关不断 | P-body/源区轮廓、功函数、界面电荷、穿通、体区连接 | 低漏压 Id–Vg、能带、载流子和体区电位 |
| Ion 偏低、Ron,sp 偏大 | 归一化、沟道迁移率、体/漂移电阻、屏蔽区夹断、接触压降 | 低压斜率、电势降、电流与迁移率分布 |
| BV 偏低 | 单位、结轮廓、晶向、雪崩参数、底角、边界和终端 | 实际端电压、I–V、雪崩及场分布 |
| 氧化层峰值场异常大 | 尖角、薄层几何、屏蔽连接、提取区域、网格依赖 | 氧化层内截线、圆角和细化对比 |
| 高压或瞬态不收敛 | 初态、步长、网格、低浓度误差、外电路和强反馈 | 完整日志、失败前曲线、残差位置及 TDR |
| 热结果异常 | 热方程是否启用、Thermode、热阻单位、缩放及衬底厚度 | 方程列表、温度、热流、输入功率 |
| 不同节点曲线差很多 | 参数分支、上游结构、旧预处理输入、AreaFactor、模型开关 | 当前树、实际输入、日志、对应结果路径 |

不要只凭最后一句日志或一张曲线归因。每次提出一个可检验假设，改动保持最小；若同类尝试持续失败，先回到来源和根因分析。
