3Calibration Project Process Search (CPPS)

The Calibration Project Process Search (CPPS) looks for experiments in a calibration
project of SentaurusTM Workbench. The tool scans process flows written in the syntax of
Sentaurus Process in the same way as DBPS. However, CPPS scans variables of the
Sentaurus Workbench. The experiments that match the search criterion are listed in the
process list file.

The search criterion - the process search pattern - consists of conditions connected by
logical operators &&, ||, !, and grouped by parentheses. The operator && means and, ||
means or, and ! means not. The conditions consist of a keyword and arguments, for
example, impl(element==As) or nimpl>0.

In general, the keyword takes only one argument. Only the impl() and diff() keywords
can have more than one argument that are connected by logical operators. Some
arguments consist of an argument type and a value connected by comparators: ==, <=, >=,
<, >, or !=. Some arguments do not have comparators or argument types.
