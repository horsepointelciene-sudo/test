      SolvNetPlus Application Notes

Additional TCAD SentaurusTM application notes are available. A complete list of application
notes, with brief descriptions, is available from the Synopsys® SolvNetPlus support site.
TCAD Sentaurus application notes are added continually to SolvNetPlus for the current release.
Check SolvNetPlus regularly for updates.

Accessing Application Notes From SolvNetPlus

To access the application notes from SolvNetPlus:
1. Go to https://solvnetplus.synopsys.com.
2. Enter your user name and password.

   If you do not have a Synopsys user name and password, then click REGISTER - CREATE
   ACCOUNT to register with SolvNetPlus.
3. Click Sign In.
   The home page of SolvNetPlus opens.
4. Search for the List of Available TCAD Sentaurus Application Examples and Notes article.
   This presents the latest index of application notes.

Accessing PDF Documentation in Sentaurus Workbench

To access the PDF documentation in Sentaurus Workbench:
1. Open a project.
2. Choose Project > Properties > Documentation > PDF File.
